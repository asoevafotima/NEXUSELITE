Безопасность аккаунта

Смените пароль спокойно и без путаницы

Теперь страница использует нормальные поля Django, показывает ошибки и корректно работает на телефоне и на компьютере.

Старый пароль Нужен для подтверждения, что пароль меняете именно вы.
Новый пароль Используйте что-то длинное и не похожее на предыдущий пароль.
Подтверждение Если поля не совпадут, ошибка сразу появится на странице.
После сохранения Система вернёт вас на сайт с понятным сообщением об успехе.

Обновление доступа

Заполните поля ниже. Если пароль слабый или текущий пароль указан неверно, страница покажет сообщение и не упадёт.

{% if messages or form.errors %}
{% for message in messages %}
{{ message }}
{% endfor %} {% for error in form.non_field_errors %}
{{ error }}
{% endfor %} {% for field in form %} {% for error in field.errors %}
{{ field.label }}: {{ error }}
{% endfor %} {% endfor %}
{% endif %}
{% csrf_token %} {{ form.as_p }}

Совет: пароль лучше делать длиннее 10 символов и не использовать имя, дату рождения или обычные слова.
